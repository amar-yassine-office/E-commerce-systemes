# E-Commerce Backend System with Crypto Payment Integration

A robust, enterprise-grade backend architecture built for modern e-commerce platforms, featuring a specialized multi-app structure and native support for cryptocurrency transactions.

## 🚀 Features

* **Multi-Currency Crypto Payments:** Seamlessly processes payments across **300+ cryptocurrencies** (including Bitcoin, Ethereum, Dogecoin, and more) for product purchases.
* **Modular Architecture:** Organized into specialized backend applications (such as `ecommerce`, `payment`, `product`, `shipping`, `catalog`, `agent`, and `accountant`) to ensure clean separation of concerns and maintainability.
* **Secure Database Models:** Implements highly precise transactional handling (supporting high digit limits and decimal precision) for digital currency ledgers and transaction states.
* **RESTful APIs & Authentication:** Secure endpoints and robust access control designed for high-performance client interactions.

## 🛠️ Tech Stack

* **Language & Framework:** Python, Django / Django REST frameworks
* **Database & Management:** Sqlite3, Django Admin Interface
* **Version Control:** Git, GitHub (`amar-yassine-office/E-commerce-systemes`)

## 📦 Project Structure

* `ecommerce/` - Core e-commerce logic and product catalog management.
* `payment/` - Advanced crypto transaction models, crypto gateway integration, and status tracking.
* `product/` - Inventory, items, and pricing definitions.
* `shipping/` - Order fulfillment and delivery logistics tracking.
* `Accountant` / `Agent` - Administrative role management and reporting modules.
